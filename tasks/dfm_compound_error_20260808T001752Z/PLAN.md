## 2. 复合误差度量（目标 3 / 3.1）—— 完整定义

### 2.1 记号

第 $i$ 条序列（$i=1..N$，$N=3136$）共享一段条件窗口，其末端的参考中间价记作 $\mu^{(i)}_{\text{ref}}$
（由 `data_cond/*_orderbook_*.csv` 最后一行取 $(\text{ask}_1+\text{bid}_1)/2$），
参考时间 $\tau^{(i)}_{\text{ref}}$。两条长度 $R=250$ 的后续：

- $y^{(i)}_m$ ——真实市场（ground truth）
- $\hat y^{(i)}_m$ ——模型自由运行（rollout）

### 2.2 观测量

每条消息是 LOBSTER 六元组 `(time, event_type, order_id, size, price, direction)`。
`order_id` 被丢弃：生成流里的 order id 是模型自造的（实测出现 `249`、`2`、`14` 这类小整数，
而真实是 `715440990` 量级），跨流不可比，放进任何分布度量都是噪声。

| 符号 | 定义 | 为什么取这个形式 |
|---|---|---|
| $\delta_m$ | $(p_m - \mu_{\text{ref}})/100$，单位 tick | 价格**位移**。绝对价没有可比性（不同序列价位不同）；位移才是扩散坐标 |
| $\lambda_m$ | $\log_{10}(\tau_m-\tau_{m-1}+\epsilon)$ | 到达间隔重尾，跨 6 个数量级，必须取对数 |
| $s_m$ | $\log_{10}(\text{size}_m)$ | 同上，size 也重尾 |
| $e_m$ | event type $\in\{1,2,3,4\}$ | 离散，直接算类别 KL |
| $d_m$ | direction $\in\{-1,+1\}$ | 离散 |

### 2.3 归一化：为什么必须除以 $\sigma_{\text{true}}(m)$

这是整个度量的关键，也是用户在目标 (3.1) 里点名的那一条。

真实的价格过程本身就是**扩散**的：$\operatorname{sd}[\delta_m]$ 随 $m$ 单调增长（大致 $\propto\sqrt{m}$）。
如果在**固定**的分箱网格上算 $\mathrm{KL}(q_m\|p_m)$，那么随着 $m$ 增大，
真实分布铺开到更多箱子里，KL 的数值会仅仅因为**真实过程自己变宽**而改变
——这和模型好不好没有关系。**不做归一化就无法区分「模型在漂」和「市场在扩散」。**

所以先把观测量按**真实**分布在该 index 上的一阶、二阶矩标准化：

$$\mu_m=\mathbb{E}_{\text{true}}[x_m],\qquad \sigma_m=\operatorname{sd}_{\text{true}}[x_m],\qquad z_m=\frac{x_m-\mu_m}{\sigma_m}$$

注意 $\mu_m,\sigma_m$ **只由真实数据估**，然后用同一组常数去标准化模型样本。
在 $z$ 坐标上取一组**跨 $m$ 共用**的固定分箱，得到直方图 $q_m$（真实）与 $p_m$（模型），报告

$$\widetilde D_m \;=\; \mathrm{KL}\big(q_m\,\|\,p_m\big)\Big|_{z\text{-网格}}$$

这样构造之后，$q_m$ 在每个 $m$ 上**按定义**都是均值 0、方差 1。
于是 $\widetilde D_m$ 的任何趋势都不可能来自真实过程的扩散，只能来自模型**形状**相对真实的漂移。
这正是要隔离出来的复合误差信号。

**对照量（必须同时报告）**：$D^{\text{raw}}_m=\mathrm{KL}(q_m\|p_m)$ 在原始单位的固定网格上算。
它把扩散和误差混在一起。两条曲线并排放，归一化那条才可信——
否则读者无法判断归一化是「校正」还是「洗掉了信号」。

### 2.4 KL 的方向

用**前向** KL $\mathrm{KL}(q\|p)$（真实在前）。它是 mode-covering 的：
凡是真实有质量而模型没有的地方，被积项 $q\log(q/p)$ 就发散。
因此**模式塌缩会被重罚**。反向 KL 反而奖励塌缩（模型只要缩到一个高频模式里就得分），
在这个任务里是错的度量方向。反向 KL 只作诊断量记录，不作判据。

### 2.5 估计量卫生（否则结论不成立）

$N=3136$ 个样本、$B$ 个箱的 plug-in KL 是**有偏的**，偏向偏大。两条处理：

1. **加性平滑**：两个直方图都加 $\alpha=1/B$，避免 $\log 0$ 发散。
2. **自助零假设带（null band）**——这条最重要。把**真实**样本随机对半分成 A/B 两份，
   计算 $\mathrm{KL}(q^A_m\|q^B_m)$，重复 200 次取分位数。
   这给出「同一个分布的两份有限样本之间」应有的 KL，也就是**地板**。
   所有 $\widetilde D_m$ 必须对着这条带读。
   没有这条带，一条平的正值 KL 看起来像误差，其实可能只是有限样本偏差。

### 2.6 复合误差的两个判据（目标 4 / 6 / 7）

在 $m\in[1,R]$ 上做 OLS 拟合 $\widetilde D_m=a+b\,m$，$b$ 的置信区间用序列级 bootstrap（重抽序列，
而不是重抽 index，因为同一条序列内的 index 不独立）：

| 判据 | 量 | 含义 |
|---|---|---|
| **趋势** | 斜率 $b$ | $b>0$ 且显著 ⇒ 存在复合误差（目标 4）。后训练后要求 $b$ 不再显著为正（目标 6） |
| **均值** | $\bar{\widetilde D}=\frac1R\sum_m \widetilde D_m$ | 整体保真度。后训练后必须更低（目标 7） |

### 2.7 长尾（目标 14）

复合误差在 LOB 上通常**先在极值上出现**。除总体 KL 外另报两个尾部量：

- **尾部 KL**：只在 $|z|>2$ 的箱上累加的那部分 $\widetilde D_m$
- **尾部质量比**：$\Pr_p(|z|>2)\big/\Pr_q(|z|>2)$，$<1$ 表示模型尾巴太瘦

## 3. 公平比较的已知陷阱（目标 8 的预备）

在做实验之前先把会被评审挑出来的点写下来，免得事后自辩：

| # | 陷阱 | 为什么是不公平 | 打算怎么处理 |
|---|---|---|---|
| T1 | **算力不匹配** | DFM 路径 = AR 起草 + $N$ 步双向修正。相对纯 AR 是「基线 + 额外算力」。赢了可能只是因为花得多 | 记录两侧 NFE；给基线配一个等算力对照（见 §4） |
| T2 | **起草用的是原始 checkpoint** | 论文的 Algorithm 3 就是这么设计的，但这意味着后训练模型享受了基线的输出作为起点 | 明确标注这是 corrector 而非独立生成器；另跑一条后训练模型独立生成的臂 |
| T3 | **回归到均值** | 修正器可能把 token 往高频模式上吸，边际 KL 变好但序列不真实 | 前向 KL 已惩罚塌缩；另加尾部质量比与 LOBbench 交叉验证 |
| T4 | **语法掩码** | 只有 33.5% 的 (offset, token) 组合合法。掩码给谁不给谁会直接改变结果 | 两侧用同一套掩码，且记录掩码来源 |
| T5 | **归一化常数泄漏** | 若 $\mu_m,\sigma_m$ 用「真实+生成」合并估，模型就参与了自己的评分 | $\mu_m,\sigma_m$ **只**由真实估，写死在代码里并加断言 |
| T6 | **同一批数据既调参又报告** | 2B 选臂若看的是同一份留出集，报告值是乐观的 | 分 dev / test 两半，选臂只看 dev，报告只用 test |
| T7 | **序列级相关** | 3136 条序列跨 20 天，同日序列高度相关，bootstrap 若按序列独立抽会低估方差 | bootstrap 按**交易日**分块重抽 |

## 8. 公平比较的对照臂设计（目标 8/9 的预备）

修正器 = AR 起草 + $N$ 次双向前向。相对纯 AR 是「基线 + 额外算力」，**赢了不算数**，
除非配上等算力对照。已确定要跑的对照臂：

| 臂 | 内容 | 控制的变量 |
|---|---|---|
| **A0** | AR 基线（已有 3136 条） | — |
| **A1** | AR 基线，best-of-$N$ 重采样（$N$ = 修正步数） | 算力 |
| **A2** | AR 基线 + **随机**修正器（$P$ 随机方向，同步数） | 「修正」本身 vs 学到的速度场 |
| **A3** | AR 基线 + 后训练修正器，**冻结 book** | book 反馈的贡献 |
| **B** | AR 基线 + 后训练修正器，**刷新 book** | 主线 |

A2 是最关键的一条：它把「多花了 $N$ 次前向」和「速度场学到了东西」分开。
若 A2 也把复合误差压下去，那么赢的是算力不是后训练。

**闸门**：每条臂开跑前必须先用**因果**模型在干净数据上复现 AR CE
（参照 0.4475，阈值 1.5）。前序工作四次迭代里三次被这道闸门判废，
而每次废掉的迭代都产出了平滑可信、完全没有意义的曲线。

## 11. 对照臂设计（目标 9）—— 一条新的、更公平的主线

原计划的主线是论文的 Algorithm 3（AR 起草 + DFM 修正）。评审的 C1/C2 指出它天然不公平：
修正路径是「基线 + 20–100 倍生成 FLOPs」，且起草本身就来自基线。

**但有一条更干净的臂，此前没被列出：**

| 臂 | 内容 | NFE | 公平性 |
|---|---|---|---|
| **A0** | 预训练权重，**因果**生成（现有 3136 条） | 1× | 基准 |
| **A4（新增主线）** | **后训练 2B 权重（trunk + P），因果生成** | **1×** | ✅ **完全等算力、等采样、无起草泄漏** |
| B | 预训练起草 + 后训练 DFM 修正（论文 Algorithm 3） | 20–100× | 需 best-of-K 对照 |
| A1 | 预训练 best-of-K，K 对齐 B 的 NFE | 20–100× | B 的等算力对照 |
| A2 | 预训练起草 + **随机** P 修正，同步数 | 20–100× | 分离「多花算力」与「学到的速度场」 |
| A3 | 同 B 但冻结 book | 20–100× | 分离 book 反馈 |

**A4 是最重要的新增**：`build_model(bidirectional=False, dfm_residual=True)` 已验证可用
（`ar_gate_and_forgetting.py` 用的就是它）。把 2B 的 trunk+P 放进现有生成链，
**与 A0 逐字节同一条代码路径、同一套采样、同一个 NFE**。

**如果 A4 赢，那是无可争辩的**：同样的算力、同样的采样器、同样的模拟器、
同样的条件窗口，只有权重不同。评审的 C1–C4 全部不适用。

**风险**：2B 解冻了主干（`sum|Δ|=3.7e4`），可能损失了 AR 能力。
`ar_gate_and_forgetting.py` 就是量这个的——它同时报
`pretrained` / `2b_trunk` / `2b_trunk+P` 三者的因果 CE。**这个数必须先测**：
若 2B 的因果 CE 远高于 0.4475，A4 会输，而那本身就是一个诚实且重要的结论
（「DFM 目标改善了 DFM loss，代价是 AR 能力」）。
