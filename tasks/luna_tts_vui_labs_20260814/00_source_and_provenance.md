## 一、三层信源，可信度依次递增

理解这篇文章的第一步，是意识到你面对的**不是一个信源，是三个**，
而它们的可核查性差着量级：

```
┌─ 第 1 层：宣传层 ──────────────────────────────────────────┐
│  公众号「机器学习算法与自然语言处理」转载新智元稿件           │
│  2026-08-15 00:22                                          │
│  性质：公司报道。目标是传播，不是取证                        │
│  可核查性：低——排名类断言无时间戳、无协议说明                 │
└────────────────────────────────────────────────────────────┘
              │ 转述自
              ▼
┌─ 第 2 层：作者自述层 ──────────────────────────────────────┐
│  arXiv:2608.11593《Luna-TTS Family Technical Report》       │
│  2026-08-12 提交，22 位作者                                 │
│  性质：技术报告（非同行评议）。作者有动机呈现好结果，          │
│        但受学术规范约束，必须标注协议与 caveat               │
│  可核查性：中高——数字、协议、局限都写明了                     │
└────────────────────────────────────────────────────────────┘
              │ 数字来自
              ▼
┌─ 第 3 层：可核查层 ────────────────────────────────────────┐
│  · 论文正文表格（Table 1–15）                               │
│  · demo 页 vuilabs-ai.github.io/luna-tts 的评测表           │
│  · 公开基准 Seed-TTS-Eval / CV3-Eval 的官方协议与工具        │
│  性质：具体数字 + 具体协议                                   │
│  可核查性：高——他人可用相同工具复现（若 checkpoint 公开）      │
└────────────────────────────────────────────────────────────┘
```

**关键发现：失真发生在第 2 层到第 1 层之间，不在第 2 层内部。**

论文自己的表述相当克制。比如：

| 论文原话 | 公众号版本 |
|---|---|
| "does not establish a statistically significant difference between Luna-TTS and Gemini" | 「**碾压**谷歌」 |
| zh SIM "sits **marginally above** Seed-TTS" (79.7 vs 79.6) | 「**显著优势**超越了字节 Seed……」 |
| "the lowest **Mandarin and English** error rates"（只说中英） | （略过了日韩与四语平均落后的事实） |
| "We regard **neither variant as dominant**" | 「语音质量最好、生成效率最高、首包延迟最低」 |
| "may differ in evaluation details"（⋄ 标记的引用数字） | （caveat 整个消失） |

所以读这类稿件的正确姿势不是"信 or 不信"，而是**顺着链条往上走一层**。
本目录做的就是这件事。

## 四、两个 Arena 不是一回事（最容易混的一点）

文章和论文里出现了**三个**带 "Arena" 的东西，它们互不相干：

| Arena | 是什么 | 谁办的 | 文章/论文里的成绩 |
|---|---|---|---|
| **Hugging Face TTS Arena** | 公开的人类盲测投票平台，任何人可以去投票 | HF 社区（TTS-AGI） | 文章称 Luna-TTS **第一**（击败 ElevenLabs / MiniMax / Cartesia） |
| **Artificial Analysis Speech Arena** | 第三方评测机构的 Elo 榜 | Artificial Analysis | 文章称 **第三**（"超越谷歌"） |
| **"Our internal English TTS Arena"** | **VUI Labs 自己搭的**内部竞技场，1319 次配对比较，100 条英文 prompt | VUI Labs | 论文 Table 14：Luna 第一（Elo 1548.47），Gemini 第二（1546.13），**差异不显著** |

公众号标题的"碾压谷歌"，语义上最接近第三个（因为只有那里有谷歌的正面对比），
但那个 Arena 是公司自建的，且论文自己说不显著。见 `04` 第二节。

**另外**：Elo 榜是**滚动更新**的。检索时（2026-08-14）看到的 Artificial Analysis
榜前列包含 Gemini 3.1 Flash TTS、Cartesia Sonic 3.5 等，与文章截图的时点不一定一致。
任何"第 N 名"的断言都必须带时间戳，否则无意义。
