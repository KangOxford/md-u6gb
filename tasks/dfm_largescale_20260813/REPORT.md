> 而这正是 field 度量的构造所预言的。

## 4. 为什么是这个交换：机制在度量的定义里

`build_field_distance_matrix` 的构造：

```
d[i, i] = 0
d[i, j] = f(|val_i − val_j|) / f(span)    同一序数字段（f = log1p）
d[i, j] = 1                               同一类别字段，i ≠ j
d[i, j] = inf                             不同字段，或 special
```

**对类别字段，每一个错的类别距离都是 1** —— 没有任何相似度梯度。
所以 field 度量下的概率路径在 `event_type` / `direction` 上退化成「对/错」二元，
残差**没有可学的方向**，容量全部投到序数字段（`price_rel`、`log10_dt`、`size`）。

A02 的残差用 `embedding` 度量。那个度量在几何上确实是坏的（代码实测：耦合比 6.69 vs
同形状**随机高斯表** 7.13；与数值距离的秩相关 price 0.237 / time 0.065），但它对类别
至少给出**某种**差异结构 —— 这解释了它为什么在 `direction` 上更强而在 `price_rel` 上更弱。

**这不是「哪个残差更好」，是「度量决定了容量投向哪些字段」。**

一个不被这个解释覆盖的例外：`size` 是序数字段，却被推坏了（修正后斜率 +0.0154/+0.0121）。
它也是 A02 里唯一「随机方向也有效」的那格。**两处异常都落在 `size` 上，值得单独查。**

## 5. 未达标 / 未回答

1. **只跑了 g2（lr=1e-4）**。g1（‖P‖=0.44）与 g3（‖P‖=9.86）未测，而 §1 说明 loss 选不出它们、只有下游能选。
2. **训练只用了 12 个月**，不是 48 个月。代码已支持 `2022-01..2025-12`，未跑。
3. **`t_cond` 分支仍然坏**（`init_dfm_params` 不造 `dfm_t_hidden`），所以时间条件化那条路没测过。
4. **`size` 的双重异常未解释**（序数却变坏；两个残差下随机方向都有效）。
5. **两个留出月相邻**，市场状态未必独立。
6. **非法消息率本轮未复核。**
