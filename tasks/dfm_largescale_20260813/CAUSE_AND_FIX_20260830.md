# 复合误差的成因与修复设计（2026-08-30）

承接 B7b 收尾（comment 5467999663）：表征修复层层生效但计数不动，驱动者不在
Issue 1（表征）。本文回答两个问题：**复合误差到底是怎么产生的**，以及
**post-training 方法要怎么改才能真正解决它**。

---

## 1. 现象的精确定义

487 ticker × 2 月，excess 分布距离（对 floor 校平）随生成深度 m 的曲线：

| 组 | 水平（m=40 附近） | 累积（m: 40→460 的爬升） |
|---|---|---|
| AR draft | **0.023（低）** | **+0.229（爬）** |
| DFM 修正后 | 0.411（高） | +0.000（平） |

**修正器用「水平」买了「斜率」**：把随深度累积的误差换成一个恒定的高偏置。
交叉点 m≈300-4700，而 rollout 只有 500 条 ⇒ 500 窗口内净为负。
「解决复合误差」= 一条曲线同时做到 **水平 ≈ draft 起点、斜率 ≈ 0**。

## 3. 因果链：三层，各自有独立证据

```
   训练时:  corrupt(REAL) ──修──> REAL          「把均匀噪声修回真实数据」
   推理时:  corrupt(DRAFT) ──修──> ???          「把 draft 的系统误差修掉」
                │
                └── L1 训练-推理分布错位（exposure bias）
                    修正器从没见过 draft 的误差模式；它把 draft 当均匀噪声，
                    于是把 draft 的正确部分也重写（E2: 64% 改动、一致率反降）。

   逐位置分解抽样  p(x_i | 上下文)  各位置独立
                │
                └── L2 采样分解摧毁联合结构
                    每一步都把联合分布往「边缘乘积」推。消息内位间相关
                    z+210→+8（E4）、字段内 MI 0.63→0.12（E10）、
                    dt 单调率 77%→56%（E5）。
                    tau=0 时输出根本不是「draft+修正」，而是 DFM 边缘律的
                    一次完整生成（run_tau_sweep.sh 已点破）——水平 0.411
                    就是这个边缘律自身的水平。

   digit 编码     (1,99)→(2,00) 差 1 tick 计满低位距离
                │
                └── L3 编码把 L2 的小错放大成 value 空间的大错
                    进位边界不连续 + time 块 1000 token 服务 14 offset。
                    B7b 只修了共用（E7 证明不够），进位不连续仍在。
```

**水平抬升 = L1（不认识 draft 的好） × L2（重画毁联合） × L3（错一位=错很多）。
斜率归零 = 每窗口都从模型平稳律重画 ⇒ 无累积——但那是换分布，不是修误差。**

## 4. 修复设计（按杠杆排序，可组合）

### R1 推理侧：把修正器约束回「修正」——keep_tau + keep_field（已实现，未收尾）

只在模型给 draft token 的概率 < tau 时才覆盖；字段内整组保/换。
E3 显示 tau=0.1 已把一致率翻正。**先收尾既有扫描**（tau ∈ {0, .01, .1, .3} ×
{token, field} 的 9 个配置产物在盘上），对锁死标准
（≥3/5 字段水平<draft 且累积≤0）出全表 → 结果见 §6。
预期机制：改得少 ⇒ 水平贴 draft；改的是模型最有把握错的 ⇒ 斜率仍受益。

### R2 训练侧：p0 = draft 分布（对 L1 的根治）

DFM 的 p0 现在是 per-field uniform；推理的真实起点是 **draft 的分布**。
把训练改成「draft→real 的流」：
- 输入 = AR draft 的真实 rollout（**数据现成**：rollouts_* 目录几千个
  draft/real 配对窗口，同前缀同长度逐 message 对齐）；
- corruption 混合：x_t = 插值(draft, real)，模型学「从 draft 出发往 real 修」；
- 这不是偏离 flow matching，恰是它的本义——p0 本就该是推理时的实际源分布。
训练成本 ~1.5h/格（与 B7b 同量级）。修正器第一次「见过」draft 哪里通常错，
改动预算花在刀刃上。

### R3 采样侧：消息级重生（对 L2 的根治）

per-token 并行分解永远守不住位间联合（E4/E10 是机制性的，不是训练不足）。
把修正单位从 token 改为**整条消息**：
- DFM 头给每条 draft 消息打「可疑度」（现有 posterior 直接可用）；
- 最可疑的 K% 消息交给 **AR 头在原上下文重生成整条**（消息内自回归保联合，
  消息间并行保效率）；
- 其余消息一个 token 都不动。
角色分解：DFM 当侦察（找错），AR 当执行（重写）——各用各的保真优势。
预期：位间 z、字段 MI、dt 单调率全部回到 draft 水平（因为写手就是 draft 模型），
而被重写的恰是误差贡献最大的消息 ⇒ 斜率收益保留。

### R2 必须携带的三个架构修正（2026-08-30 晚，三份组件审计的结论）

对 P 矩阵、embedding、causal→bidirectional 的专项审计
（AUDIT_P_MATRIX / AUDIT_EMBEDDING / AUDIT_BIDIRECTIONAL 三个文件）发现，
现有修正头的表达力被三道架构约束卡死，**只换训练分布（R2）而不解锁表达力，
新信号也说不出「这里别动」**：

| 修正 | 针对 | 改动 |
|---|---|---|
| a. LN 门控化 | LN 抹掉幅度，「安静」选项不存在 | `res = σ(w·h)·RMSNorm(h@P)` 或 per-dim 零初始化门控 |
| b. t 条件打开 | 生产路径 `t_cond=False`，模型不知道自己在哪层 | 代码已在（dfm_t_cond），置 True 并喂 t |
| c. bidirectional 校准层 | 冻结 causal 参数跑对称 mask = 未训练的函数 | 每层 SSM 输出后零初始化 per-channel affine，随 R2 同训 |
| d. 残差上下文化（可选第二格） | h_embed 无上下文，修正上限=token 边缘 | h_embed 拼上主干中层 hidden |

**先行分离实验（已完成，2026-08-31）**：P=0 纯双向格的 level 是灾难级
（event_type +1.28 vs 学习版 +0.19 vs draft +0.02）——**双向结构效应是
水平损伤的主源，P 残差大部分在补偿这个自伤**；斜率修复是学出来的
（纯双向格无负 slope）。详表见 AUDIT_BIDIRECTIONAL §4.1。
推论：架构修正 c（校准层）升为必做，且「放弃对称 mask、两遍 causal」
（audit 三的 b1）作为第二格的对照配置。

### 组合与预期

R1 已被 §6 否定（信号缺失是机制性的）；R2（换训练分布 + 上述 a-c）是
关键路径；R3（消息级重生）建在 R2 的信号之上。三者正交可叠加。
L3（编码）是 Line C 的领地，本轮不动词表——R3 恰好也绕开了它
（消息级 AR 重生不经过 per-digit 并行分解）。

## 7. R2 第一格结果（2026-08-31 晚）：分布修复单独不够，失败形态验证架构诊断

四格（{d1=带 offset 表, d0=无} × {s42, s43}，同一份 57 文件语料快照、
8000 步、与 b7b 完全同超参）× 2026-01 开发月推理，全部 **0/5**：

| 格 | 最好字段 | 爆点字段 | price_rel slope |
|---|---|---|---|
| r2d1_s42 | event_type +0.084 | **price_rel +1.008** | +0.607 |
| r2d1_s43 | direction +0.024（slope −0.009） | **size +1.534** | **−0.113** |
| r2d0_s42 | direction +0.055 | log10_dt +0.664 | **−0.209** |
| r2d0_s43 | direction +0.199 | size +1.536 | +0.093 |

三个新病理，都指向「信号到了、管道扭曲」：

1. **时间戳过冲**：R2 格 dt>0 = 97.7-99.3%（real 72%、draft 77%）。
   B7b 修复过冲 +11pp，R2 过冲 **+26pp**——「real 的时间往前走」被学成
   过强先验，而残差架构没有幅度旋钮（审计一 §2.1），只能全力输出。
2. **位间反相关加深**：排除共零后 hi-mid 的 z 到 −100~−146（r2d0）/
   −30~−40（r2d1）——旧版是「独立化 +8」，R2 把它推到反相关。
3. **爆点随种子换位置**：s42 爆 price_rel、s43 爆 size——高方差，
   不是稳定改善。

保留的正信号：price_rel 斜率在 2/4 格转负（斜率修复的种子在）；
offset 表在 R2 分布下仍有 4-5 倍 event_type 增益（d1 vs d0）——
表征修复与分布修复正交，两者都要。

**判定**：R2-只换分布 ≠ 修复。失败形态与 §4 的预言一致——「只换训练
分布而不解锁表达力，新信号也说不出『这里别动』」，现在有了四格实证。
**第二格（R2 + 架构修正 a/b/c）从计划升为必然**；其中 a（LN 门控化，
给模型「安静」选项）直接对症病理 1 与 3。

## 5. 验收口径（沿用已冻结规则）

- 开发月 2026-01（本文所有扫描），验收月 2026-02 只跑注册配置一次；
- 5 字段 level/slope 分报；每采样种子对自己的 draft；n_seq=32 口径
  （tau 旧产物是 n_seq=8，只做方向判断，入验收前重跑 32）；
- 目标：≥3/5 字段水平 < draft 且累积 ≤ 0（run_tau_sweep.sh 锁死的标准）。

## 6. tau 扫描收尾结果：R1 被机制性否定，靶子移到 R2

9 配置 × 60 ticker（2026-01，n_seq=8 口径）全部 0/5，但形态说明一切：

| 配置 | 水平 | 斜率 |
|---|---|---|
| tau=0（纯修正器） | 灾难（size +0.94 vs draft +0.23） | **修复真实**（price_rel −0.04 vs draft +0.22） |
| tau=0.01/0.1/0.3 | 贴回 draft（event_type +0.067 vs +0.064） | **优势全丢**（price_rel +0.224 ≈ draft +0.221） |
| keep_field 变体 | 同上 | 同上（kf14k_t01 的 price_rel +0.16 略好，仍在爬） |

**tau 从 0 到 0.01 之间是断崖，不存在「水平低 + 斜率平」的中间点。**

机制：draft 是模型自己采样的，几乎每个 draft token 在模型自己看来都是
高概率 ⇒ **模型自身置信度不含「此 token 携带分布漂移」的信息** ⇒
keep_tau 按这个信号只能挑出句法级错误 ⇒ 保 draft 的 token 就保了 draft
的全部累积误差。E3 的 token 一致率反超没有转化成分布距离改善。

**推论**：任何按「当前模型的置信度」决定改不改的推理侧方案（keep_tau、
keep_field、top-K commit）都卡在同一个信号缺失上。要让「哪里错了」的信号
存在，模型必须**在训练里见过 draft 分布**——这正是 R2。R3（消息级重生）
的「找可疑消息」同样依赖这个信号，所以 **R2 是关键路径，R3 是 R2 之上的
采样机制**，R1 退为 R2 训好之后的辅助旋钮。

## 8. R2 第二格结果（2026-09-01）：门控残差 —— 定向有效，但被网络其余部分吸收

**全部图与数字**：`sigma-0` 分支 `feat/dfm-r2-draft-corpus-20260830` 的
`post_training/dfm/analysis/compound_error_r2.ipynb`（图已嵌入，GitHub 直接可读）。

### 8.1 改了什么

`res = LN(h @ P) * sigmoid(h @ w + b)`，`w` 零初始化、`b = −2`（默认开度约 0.12）。
动机来自 §4 的架构诊断：LayerNorm 把任何非零方向重整到单位方差，模型**没有「小声说话」
这个选项**，而 34–47% 的 draft token 本来就是对的。门给它这个选项，且 P=0 时保持恒等。

单变量：与 r2d1 只差这一个门，语料、步数、lr、种子全同。

### 8.2 判定：0/5，两个种子

| 格 | 种子 | level<draft | slope≤0 | 两者同时 | 结论 |
|---|---|---|---|---|---|
| R2 未加门 (r2d1) | 42 / 43 | 0/5 · 0/5 | 0/5 · 3/5 | 0/5 · 0/5 | fail |
| R2 加门 (r2g1) | 42 / 43 | 0/5 · 0/5 | 0/5 · 0/5 | 0/5 · 0/5 | fail |

### 8.3 失败形态变了，这才是信息

**门在它瞄准的地方确实起作用**（两个种子同向）：

| 指标 | 真实 | draft | r2d1 未加门 | r2g1 加门 |
|---|---|---|---|---|
| dt>0 比例 s42 / s43 | 72.1 / 71.8 | 76.7 / 77.0 | 97.7 / 98.2 | **93.9 / 92.8** |
| size 斜率 ÷ draft 斜率 | — | 1.00 | 0.55 / 1.12 | **0.07 / 0.22** |

**代价出现在别处**：level 两种子都变高；数位相关（真实 z=+235）从未加门的
+42 反转到 **−175**，比未加门更远离真实。

**机制在 gate 参数里**（两种子几乎同值，是结构性反应不是噪声）：

| 量 | 初始 | r2g1_s42 | r2g1_s43 | 读法 |
|---|---|---|---|---|
| `‖w‖` | 0 | 3.173 | 3.165 | 门**离开了零初始化**，是输入依赖的，不是常数阻尼 |
| `sigmoid(b)` | 0.119 | 0.131 | 0.131 | 默认开度几乎没动（b: −2.00→−1.89） |
| `‖P‖_F`（对比 r2d1） | — | 11.86 (vs 8.46) | 11.81 (vs 8.40) | **投影长了 40% 把门顶开** |

**门没有输给噪声，输给了联合训练路径的补偿。** 在残差路径的一个点上施加约束，
被同一路径的别处吸收掉了——这是比「门无效」强得多的结论，它说明单点约束这一类
做法整体不成立。

### 8.4 跨六格的不变量（这是主结论）

`level(corr) > level(draft)`，**40/40 个 (格, 字段, 种子) 组合无一例外**。
六个格在训练分布、有无偏移表、投影是否训练、残差是否加门四个维度上都不同，
**没有一个改变符号**。

### 8.5 两条诚实性说明（notebook 里逐种子画出来的原因）

1. **斜率上两个种子在 5 个字段里有 4 个符号相反**，只有 `size` 两种子都低于 draft。
   按种子平均会把分歧藏掉，所以图里画的是逐种子的点，中间连线表示两种子的跨度。
2. **加门格一次都没进过 slope≤0 的目标区**，而未加门格在种子 43 上有 3 个字段进了。
   门缩小了增长的绝对值，却让它再也过不了零。

### 8.6 held-out 完全看不见以上任何差别

两格 held-out 从 1000 步起平在 3.85–3.97，与未加门格同一平台。
**判定只能来自 rollout，不能来自训练损失。**

### 8.7 下一步指向采样器，不是修正器

到此为止六个格改的都是**残差修正**，而始终不变的两件事——逐位置分解采样，
以及分数位编码——恰好对应始终不改善的两个测量（数位联合结构、level 下限）。
下一轮应改采样机制（R3 消息级重生），而不是继续调修正器。
