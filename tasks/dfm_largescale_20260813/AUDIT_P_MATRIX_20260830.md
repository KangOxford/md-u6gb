# 审计一：残差投影 P（`dfm_residual_proj`）——它能学什么、被什么卡死

应用户问（2026-08-30）：「learnable params P matrix，我怀疑这里多少有点问题。」
结论先行：**怀疑成立。P 本身无罪，但它被三道架构约束卡死——LayerNorm 抹掉幅度、
输入无上下文、单表服务全部位置与全部 t 层。修正头的表达力上限是
「per-token 的边缘 logit 偏置」，这恰好与生成侧「边缘对、联合毁」的观测吻合。**

## 2. 问题清单（按对复合误差的贡献排序）

### 2.1 LayerNorm 抹掉幅度：「安静」这个选项在架构上不存在

`res = LN(h@P)`。LN 把任何非零输入重新归一到单位方差再乘一个
**全 d_model 共享**的 scale。后果：

- 模型**不能**通过把某方向的 P 学小来「在这类 token 上少改一点」——LN 会把
  缩小的向量重新放大。位置级/token 级的幅度自适应通道被掐断。
- 唯一幅度旋钮是 LN 的 scale/bias——全局的。全局缩放已被实测否证：
  alpha 扫描里 `event_type` 的水平代价随 alpha 减小**单调上升**
  （+0.09 → +0.75，run_tau_sweep.sh 头注），「全局调小」=「加满噪 + 修不动」。
- draft 与 real 的 token 一致率是 34-47%——**大多数位置 AR 本来就对**，
  而残差在这些位置上仍然全力注入一个单位方差向量。
  这是「水平抬升」的直接机械来源之一，B7b 说明文档 §5 自己点过名
  （「模型没法在 AR 主干本来就对的位置上安静下来。这个缺陷 B7b 不修」），
  **至今没有任何一版改动碰过它**。

顺带一个启动期注脚：P 零初始化 ⇒ 首步 h@P=0，LN 在零点的 Jacobian 量级
是 1/√eps ≈ 10³——前几十步梯度被放大三个数量级（warmup=0, lr=1e-4）。
它训出来了，所以不是致命伤，但任何重训（R2）都建议加 warmup 或把
LN 换掉（见 §3）。

### 2.2 输入无上下文：修正头的上限是「token 边缘统计」

h_embed 是 **SSM 之前**的裸 embedding（702-704 行）。残差分支整体是
`token 身份 → (+26 偏移) → P → LN` 的**静态查表**：它看不到邻居 token、
看不到主干对当前上下文的判断。它能学到的最优解是
「在 t 层平均而言，这个 token 的 logits 该往哪拧」——**一个条件边缘修正**。
上下文相关的修正只能指望冻结主干的输出 x——而主干（见审计三）在
corrupted 输入 + bidirectional 结构上是 off-distribution 的。

这与生成侧观测精确对上：修正器输出「字段边缘更近、位间联合更毁」
（real 位间 z≈+210 → corr +8；size 字段内 MI 0.63→0.12）。
**per-position 采样毁联合是一半原因，修正信号本身只含边缘信息是另一半。**

### 2.3 一张 P 服务 26 个 offset × 8 个 t 层

- offset 侧：B7b 加的是**加性**偏移（h+E[off]）——26 个角色共用同一个
  投影方向集，角色差异只能是输入平移，不能是不同的投影。B7b 结果
  （teacher-forced −0.53、计数 0/5）已经量出这条路的上限。
- t 侧更彻底：`t_cond=False`（runner:892）——**修正器在生产路径上根本不知道
  自己在哪个 t 层**。strata 显示不同 t 层的损失差 3.54→3.13，
  「t=0.8 只需小修、t=0.3 要大改」这种幅度调度，架构上没有输入端。
  （t 条件的代码存在——`dfm_t_cond`，555-560 行两层 MLP + (1+gamma) 门——
  写好了没用上。）

### 2.4 residual_scale 旋钮乘错了位置（次要但要知道）

runner 856-864：`--residual-scale` 把 **LN 的 scale 和 bias** 一起乘。
bias 也被乘意味着它不只缩放学到的修正方向，还移动 LN 的输出基点——
与「把残差整体调小」的直觉不完全等价。alpha 扫描的反方向结果
有一部分可能来自这个实现选择（未分离，标注存疑）。

## 3. 对修复设计（R2/R3）的直接含义

1. **换掉 LN 或给它旁路**：最小改动是 `res = g ⊙ (h@P)`，g 为 per-dim
   可学门控（零初始化），或 RMSNorm × per-token 标量门
   `res = σ(w·h) · RMSNorm(h@P)`——把「这个位置改多大」还给模型。
   一行级改动，与 R2 重训同车。
2. **打开 t 条件**（代码已在，`t_cond=True` + 训练时喂 t）。
3. **给残差上下文**：h_embed 换成（或拼上）主干中层 hidden——
   零新增机制（读一个已有张量），修正头从「边缘」升级到「条件」。
4. R2（p0=draft 训练）**必须**至少带 1 和 2，否则新训练分布仍被同一个
   表达力天花板压着——训练信号再对，头也说不出「这里别动」。

## 4. 一个待跑的分离实验（已有开关、从未出数）

`--random-p --random-p-scale 0.0`（runner 869-877）= **P=0、纯 bidirectional
前向**的消融。它把 −0.53 的 teacher-forced 增益拆成
「bidirectional 结构带来的」与「P 残差带来的」两份——审计三会说明
为什么这个分离很重要。一次推理成本，建议与 R2 第一格同批跑。
