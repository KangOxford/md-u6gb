# 标准化流程：一个分析在什么条件下才算可信

任何 `Axx_*/` 文件夹在写 `REPORT.md` 之前，必须逐条满足下面 7 条闸门。
**不满足就不报数字**，把没过的那条写进 `REPORT.md` 的「未达标」一节。

---

## G1　先写 `PLAN.md`，把判据写死在跑之前

`PLAN.md` 必须包含：**问题一句话**、**判据（什么数字出现算 YES / 算 NO）**、**对照臂清单**、**已知会造假的伪影清单**。
跑完之后**不允许**改判据。改了就新开一个编号，旧的保留并注明被取代。

**为什么**：这条线上出过「整晚扫超参找 5/5」，事后才发现被排名的是噪声。判据后定 = 在噪声里挑一个好看的。

## G2　零假设必须是**测出来的**，不是 0

$D_m$ 是 KL 的插值估计，**恒为正**且有 $\sim K/(2n)$ 的有限样本偏差。
所以「$D_m > 0$」不说明任何事，「$D_m$ 的斜率 $> 0$」也可能是管线造的。

**必须构造一条 floor 臂**：拿**真值流**走**完全相同的管线**（同样的分箱、窗口、格点、重抽）。
判据一律写成 **excess = model − floor**，而不是 model 对 0。

**两侧样本量必须相等**。KL 偏差 ~ $K/(2n)$，一侧 n 少一半 floor 就高一倍。
本目录统一用**对称跨半**估计量：

$$D_m^{\rm model}=\tfrac12\big[\mathrm{KL}(P^{\rm true}_A\|P^{\rm gen}_B)+\mathrm{KL}(P^{\rm true}_B\|P^{\rm gen}_A)\big],\quad
D_m^{\rm floor}=\tfrac12\big[\mathrm{KL}(P^{\rm true}_A\|P^{\rm true}_B)+\mathrm{KL}(P^{\rm true}_B\|P^{\rm true}_A)\big]$$

两边都是 $n/2$ 对 $n/2$ 的不相交比较，偏差**按构造相同**，在差里精确抵消（不是渐近抵消）。
且 model 侧两边永远不共享序列 —— 共享会让两个经验直方图一起动，压低 model 的膨胀而 floor 不受影响。

## G3　重抽单位 = 交易日，两臂共享同一个抽取矩阵

- 按**交易日**有放回重抽（不是按序列、不是按窗口）。同一天内的序列高度相关，按序列重抽等于假装独立。
- 所有臂共用同一个 `draws` 矩阵，重抽的是**差值**，共同的日间噪声相消，还一阶抵消 KL 这个凸估计量的 Jensen 膨胀。
- **看到零宽度 CI 或「100% 的重抽都更好」立刻停下查分层**，那是重抽单位选错的诊断信号，不是强证据。

实现上：先把每天每格点的**分箱计数**存成 `counts[day, grid, bin]`（分箱计数是精确充分统计量），
重抽退化成对 day 轴的加权求和 —— 既精确又便宜，200 次重抽几乎免费。

## G4　功效必须标定：注入已知强度的缺陷，看多大才检得出

只报「CI 排除 0 / 含 0」是不够的 —— **含 0 可能是没有效应，也可能是没有功效**。
每个分析必须跑一条**注入臂**：把已知强度 $\delta$ 的线性 drift 注入生成流，扫 $\delta$，
报出**检出阈值**。`REPORT.md` 里「未检出」这句话必须紧跟着「本设置能检出的最小效应是多少」。

同时报**分辨率** = |对照| / 蒙特卡洛 sd。小于 ~2σ 的结论一律标为未分辨，不进结论表。

## G5　伪影清单逐条排除，每条一个独立对照

至少覆盖：

| 伪影 | 对照 |
|---|---|
| KL 有限样本正偏差 | G2 的 floor 臂 |
| 窗口在右边界收缩 → 样本量下降 → KL 虚高 → 末端翘起 | 只用**全宽窗口**的格点；同时报截断版做对比 |
| 分箱范围猜错 | 用**真值分位数**分箱。固定范围曾排除真值 47.9% 的质量并把符号弄反 |
| 非法输出被静默丢弃 | 单独一个 **ILLEGAL 桶**，计入 KL 而不是 drop |
| 近原子分布在起点造假尖峰 | 事先声明 `FIT_FROM`，不用全区间拟合 |
| 「上升」其实来自真值自身的非平稳 | floor 臂天然吸收（真值对真值） |

## G6　水平与斜率分开报，不许合并成「改善」

`level` 和 `slope` 是两个主张，实测会反向。**"compound" 指的是斜率。**
恒定缺陷（如与位置无关的非法率）对斜率零贡献、对水平加常数 —— 所以斜率结论对它免疫，水平结论不免疫，必须分别注明。

## G7　产物自带身份，结论只从机器可读的侧车读

- 输出文件名带上决定结果的配置（horizon / 臂 / checkpoint step），**物理上无法互相覆盖**。
  `skip-if-exists` 是续跑守卫不是冲突守卫，两个配置写同名文件时慢的那个会后写盘覆盖快的那个。
- 数值一律从 `npz`/`json` 读，**不从人读的日志 grep**。
- 对照臂要有 **bit-exact canary**：把处理做成 no-op 后输出必须逐位相同，否则非零退出。
- 撤回一个结果之前，先用带身份的产物**重跑一次**再决定。

## `REPORT.md` 的固定骨架

```
# Axx 标题
UTC 时间戳 · 数据 · 规模（n_seq / n_gen / n_days）

## 0. 结论先说          ← 一张表，每行一个结论 + 证据指针
## 1. 判据（引 PLAN）    ← 证明没有事后改判据
## 2. floor 与功效标定    ← G2 + G4，没有这节的报告不成立
## 3. 主结果
## 4. 伪影排除逐条        ← G5
## 5. 未达标 / 未回答
## 6. 产物清单（绝对路径）
```
