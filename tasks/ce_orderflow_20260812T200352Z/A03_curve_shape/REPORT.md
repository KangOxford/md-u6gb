# A03 —— 复合误差的形状：水平与斜率是两个主张

\skim{DFM 后训练**消掉了误差的累积（斜率），抬高了水平**。全量 487 ticker × 2 月、
配对自举：斜率 5/5（1 月）和 4/5（2 月）字段显著优于 draft，`price_rel` 的**绝对
斜率转负**（误差随深度缩小）；水平只有 `direction` 显著更好。`size` 的 +0.72
既不是非法消息也不是残差噪声 —— 学到的残差在那一个字段上比**同范数随机方向差 1.7 倍**。}

## 0. 一句话结论

| | 主张 | 判据 | 结果 |
|---|---|---|---|
| **斜率** | 复合误差降低了 | Δ斜率 < 0 且 CI 不含 0 | **5/5 (1月) · 4/5 (2月)** |
| **水平** | 没有为此付出水平代价 | Δ水平 < 0 且 CI 不含 0 | **1/5 · 1/5**（仅 `direction`） |
| **E7 合判** | ≥3/5 字段两者兼得且跨月复现 | 见 §3 | **0/5，未达成** |

## 1. 为什么必须两个都报（PR2）

斜率是把一条曲线压成一个数，它编码「涨得多快」，**对起点携带零信息**。两者可以
反向移动，而这在本项目里真实发生过：A02 报了 `corr − draft = −0.0612 REDUCED`，
作为斜率差**是真的**，而修正臂在**每一个实测深度上都更差**（`price_rel` 0.411 vs
0.023）。报告在自己的定义内自洽，却没有回答用户问的任何问题。

**结论：先画曲线，再拟合。**

## 2. 估计量

出处 `A01_does_ce_exist/code/a01_ce_existence.py:137-151`。对称交叉半样本，
基底按构造被减掉：

```
D_m^arm   = ½[KL(t_A‖g_B) + KL(t_B‖g_A)] / H_m
D_m^floor = ½[KL(t_A‖t_B) + KL(t_B‖t_A)] / H_m
超出基底  = D_m^arm − D_m^floor
复合误差  = slope(超出基底 vs m) × 100
```

本次分析的改动：**配对自举**。npz 里存的是每条臂各自的边缘 CI，用「两条边缘 CI
是否重叠」判断差异在配对数据上**保守到错** —— draft 与 corr 测在同一批 487 个
ticker 上，ticker 之间的异质性（`price_rel` 跨数量级）同时抬高两条边缘 CI，
而那部分方差在**差值**里会抵消。重采样单位仍是 ticker，被平均的换成逐 ticker 的差。

代码 `code/a03_verdict.py`。

## 4. `size` 的 +0.72 是什么，不是什么

两个独立对照定死了它。

**不是非法消息。** 剔除非法箱后修正臂的曲线最多动 **0.003**（`direction` 恰好
0.0000）—— R2/R3 的修复真的把非法质量清干净了，+0.723/+0.701 完全活在**合法**的
size 分布里。（修复前不是这样：那时剔除非法箱会让水平代价大幅缩小。）

**不是残差噪声。** 对同 Frobenius 范数的**随机方向**臂，m=440：

| 字段 | corr | rand | corr/rand |
|---|---:|---:|---:|
| `event_type` | 0.151 | 1.526 | **0.10×**（学到的好 10 倍） |
| `size` | 0.958 | 0.580 | **1.65×**（学到的差 1.7 倍） |

四个字段上学习大幅帮忙、一个字段上**主动添乱**。这不能用「残差本来就有破坏性」
解释 —— 那是目标函数奖励出来的一个**系统性变换**。

而目标函数正是 field 度量下的去噪损失，那条度量在 `size` 上可证明坏掉：
`size` 是 2 位 base-100，99 = (0,99) 与 100 = (1,0) 数值相邻却在低位上**最远**，
`P(99)/P(101) = 1.5e-26`（值空间度量下是 **1.000**）。

**于是这条从「能描述的缺陷」变成了可证伪的因果预测**：用值度量重训，必须
**特异地**消掉 `size` 的异常，而不影响学习已经帮上忙的那四个字段。

## 5. 一个后来才明白的结构事实

`predict_x1`（`dfm_sampler.py:126-133`）对**每一个**可编辑位置都从模型 logits
重新抽样，只保留位置 0。所以：

> **「修正臂」不是「draft + 修正」，它是 DFM 模型自己的一次完整生成。**

推论：
- `level(修正)` = DFM 模型边缘律与真实的距离；`level(draft)` = AR 模型的
- 修正臂**平**，是因为每步都以钉住的真实上下文重新条件化
- **缩残差（`--residual-scale`）不是 draft↔修正的插值**，实测否证：
  `event_type` 的水平代价随 α 变小**单调上升**（+0.094 → +0.754，8 倍），
  因为步间重新加噪与 α 无关，α→0 的极限是**腐蚀**而不是 draft

真正的旋钮是 `--keep-tau`：只在模型给 draft token 的概率低于 τ 时才覆盖它。
