## 1. 判据（引 `PLAN.md` §2，写在跑之前）

$\text{excess}_m = D_m^{\rm draft}-D_m^{\rm floor}$，判 **YES** 当且仅当 `slope(excess)` 的日块 bootstrap 95% CI 完全在 0 以上。
判 **NO** 分两种：`NO-detected`（点估计大于可检下限）与 `NO-power`（小于下限，不能说没有）。
「compound」**指斜率**；水平单独报，不合并。

## 2. floor 与功效标定

### 2.1 四条对照全部按事先声明的预期通过（`out/a01_selfcheck_g1000.json`）

| 对照 | 预期（写在跑之前） | 实测 | |
|---|---|---|:-:|
| **C6** no-op canary（gen := true） | excess 必须逐格点 ≡ 0 | 五个字段 `max\|excess\| = 0.000e+00` | ✅ |
| **C4** 恒定缺陷（bin-shift，δ₀ = 0.02…0.20） | 水平升、斜率 ≈ 0 | 四个强度 × 五个字段，**假阳性斜率 0 个** | ✅ |
| **C5** 线性 drift（mode collapse） | 单调可检出，给出阈值 | δ=0.20 处 5/5 检出；δ* = size 0.05、log10_dt 0.05、direction 0.10、event_type 0.20、price_rel 0.20 | ✅ |
| **C3** 沿 $m$ 打乱真值 | 斜率落回 floor | 五个字段斜率 −0.0018…−0.0002，CI 均含 0（`price_rel` 为**负**且显著，见下） | ✅ |

**C4 是承重的那条**：它证明「斜率」判据对**恒定缺陷免疫**，所以 14.7% 的非法率不会污染 §3.1 的任何结论。

### 2.2 每个格子的可检下限（1.96 × 蒙特卡洛 sd）与分辨率

`NO` 必须配一句「本设置能看见多小」，否则「没检出」和「没功效」分不开。

| field | 2× 分辨率 | 3× | 4× | 8× | 判定 |
|---|---:|---:|---:|---:|---|
| **`size`** | **3.16σ** | **4.36σ** | **4.56σ** | 0.91σ | 前三个 YES |
| **`log10_dt`** | **3.53σ** | **2.84σ** | **1.90σ** | 0.11σ | 前三个 YES |
| `event_type` | 0.69σ | 0.88σ | 1.88σ | 1.22σ | 从未过 2σ |
| `direction` | 0.85σ | 0.20σ | 1.43σ | 0.52σ | 从未过 2σ |
| `price_rel` | 0.58σ | 0.69σ | 2.02σ | 2.13σ | floor 被污染，见 §4 |

**除 `size` / `log10_dt` 外，没有任何字段在任何 horizon 上达到 2.8σ。**

### 2.3 自检暴露的两个**我自己的**设计错误（都已修，记录在此）

1. **floor 的参数顺序写反**：`D_curve(tA,tB,tB,tA)` 展开是 $\frac12[\mathrm{KL}(t_A\|t_A)+\mathrm{KL}(t_B\|t_B)]\equiv 0$ —— floor 形同虚设。C6 canary 会抓到（excess 不为 0）。**这条正是设 canary 的全部理由。**
2. **第一版注入探针是退化的**：分位数分箱让真值在箱上按构造均匀，而**循环**移位保持均匀 ⇒ 对 `price_rel` / `log10_dt` 是分布意义上的恒等变换，δ=0.40 都检不出。改成非循环（顶端截断）+ mode collapse 后才有功效。

### 2.4 一条独立发现：forward KL 会奖励过度离散

C4b 把 δ₀ 的合法码替换成均匀码（把 $q$ 摊宽），forward KL 的 excess **变成负的**：

| δ₀ | `price_rel` KL level | `price_rel` JS level |
|---|---:|---:|
| 0.05 | **−0.0739** | −0.00236 |
| 0.20 | **−0.1109** | −0.00646 |

$\mathrm{KL}(p\|q)$ 惩罚的是「$q$ 在 $p$ 大的地方小」，把 $q$ 摊宽反而降低惩罚。C3 打乱实验独立复现同一现象（`price_rel` level −0.1122）。
**后果**：一个仅仅过度离散的模型能拿到低 $D_m$，「没有 compound error」可能是离散度买来的。
**处置**：全程并报 **JS**（对称、有界，买不到）。§3.1 的 YES 判定 KL 与 JS 在 `size` 上 3/3 一致、`log10_dt` 上 2/3 一致（4× 处 JS 判 n.s.）。

### 3.2 斜率随 horizon 衰减，全部是拟合区间的效应

把**每个 horizon 都重新拟合在同一个窗口 [40,440]** 上：

| field | 2× | 3× | 4× | 8×（n_seq 减半） |
|---|---:|---:|---:|---:|
| `size` | +0.0239 | +0.0219 | +0.0209 | +0.0131 |
| `log10_dt` | +0.0242 | +0.0233 | +0.0205 | −0.0053 |
| floor `size` | −0.0019 | +0.0035 | +0.0018 | +0.0152 |
| floor `log10_dt` | −0.0021 | −0.0002 | +0.0016 | +0.0144 |

**三个 n_seq=64 的 run 在同一窗口上给出几乎相同的早期斜率（相差 < 15%）** —— 这是三份独立 rollout 的内部复现。
所以 §3.1 里斜率随 horizon 下降**不是误差在减小，是同一条饱和曲线被拟合在越来越长的区间上**。

逐 500 条分块的斜率（draft）直接看出饱和：

| field | horizon | [40,440] | [440,940] | [940,1440] | [1440,2440] | [2440,3440] |
|---|---|---:|---:|---:|---:|---:|

| `size` | 4× | +0.0209 | +0.0086 | +0.0040 | | |
| `size` | 8× | +0.0131 | +0.0160 | −0.0060 | −0.0016 | −0.0013 |

| `log10_dt` | 8× | −0.0053 | +0.0030 | +0.0019 | +0.0035 | −0.0001 |

> **误差几乎全部在头 ~500 条生成消息里积累完，之后进入一个平台。**
> 这不是「无界复合」，是**漂移到一个错误的定态**。

### 3.3 「500 太短」这个假设方向是反的

| horizon | n_seq | floor level（`price_rel` / `size` / `log10_dt`） | 五个字段里 YES 的数量 |
|---|---:|---|---:|
| 2× | 64 | 0.153 / 0.014 / 0.015 | 2 |
| 3× | 64 | 0.206 / 0.013 / 0.016 | 2 |
| **4×** | 64 | 0.269 / 0.010 / 0.025 | **3** |
| 8× | **32** | **0.647 / 0.056 / 0.069** | 0（+1 个伪影） |

8× 的 floor 高 5–8 倍，因为它只有 32 条序列、半分后每侧 16 条，而 KL 偏差 $\sim K/(2n)$。
**延长 horizon 不会让 compound error 更清楚**：它把误差摊薄（§3.2）同时把地板抬高。

两者同 draft、同步数、同掩码、同 $\lVert P\rVert$，**唯一差别是方向**。

### 3.5 水平：三分之二是同一个常数

修正臂在**每个字段**上的水平都比 draft 高 ~0.21–0.24，而且各字段高得几乎一样多 —— 这是 14.7% 非法消息进 ILLEGAL 桶的**恒定**贡献。

`direction` 是模型几乎没有其它误差的字段（draft level 0.028），可以干净地隔离它：

$$-\log(1-0.147)/\log 2 = \mathbf{0.2296}\quad\text{vs}\quad \text{实测 } 0.2365-0.0280=\mathbf{0.2085}\ \ (\text{吻合 } 91\%)$$

按 C4，恒定缺陷**对斜率零贡献**，所以 §3.1 与 §3.4 的斜率结论不受它影响；**水平结论受**。

$z=(\mu_{\rm gen}-\mu_{\rm true})/\sigma_{\rm true}$，图 `figs/fig3_mean_drift.png`。

**而 8× 处它的 $D_m$ 斜率是 +0.0002（0.11σ，判「无 compound error」）** —— $D_m$ 用真值的矩标准化，对「形状对、中心错」几乎免疫。**两个量必须都测。**

## 5. 未达标 / 未回答

1. **单标的、单月**（GOOG 2026-01）。跨标的没做。
2. **8× 只有 32 条序列、且缺随机-P 对照臂**，该 horizon 的一切只能当探索。
3. **`NO` 几乎全是 `NO-power`**：`direction` / `price_rel` 的真实斜率若小于 0.007–0.07，本设置看不见。要回答「确实没有」需要更多**交易日**（现在 20 天），不是更多序列。
4. **饱和的机理未查**：是模型漂到一个错误定态，还是分位数分箱在长程上失效？A03 该做的是这件事，**而不是**继续加长 horizon。
5. **14.7% 非法率的根因未查**（A07）。它现在压住了全部水平类结论。
6. $z(m)$ 的 CI 已算（`z_slope_ci`）但未进结论表，因为 $z$ 只在合法消息上取均值 —— 那 14.7% 被排除在外，是一个方向明确的偏袒。
