## 1. 为什么要单独查这一格

`price_rel = (price − ref_mid)/tick`，`ref_mid` 是**每条序列一个常数**（条件窗口末的中间价）。
所以它是**相对固定锚点的水平量，不是差分量** —— 作为水平量它应当比任何其它字段都更容易累积。
A01 却在四个 horizon 上都判 n.s.。**先验与观测冲突时，先查仪器。**

本页的三个测量**都不经过分箱散度**：越界比例、median \|price_rel\|、以及衰减的算术。

## 2. 测量

真值支撑集 = 真值分位数的首末边（4×：`[−1108.5, +1094.0]` ticks），所以真值越界质量按构造恒为 0。

两条读法：

- **越界比例单调增长 = compound error**，四个 horizon 全部成立，draft 与 corr 都成立。
- **漂移跟随率**：真实价格在 rollout 里越走越远（真值 median \|price_rel\| 在 4× 上涨 15 倍），
  **预训练模型基本不动**（跟随 −25% ~ +9%），**DFM 后训练把它拉到 68%–115%**。

`p99 |price_rel|`（同一份数据）：真值 ~1004–1085 ticks 全程平稳；
draft 从 1222 跳到 **21475** 并停在那里；corr 从 1027 涨到 6618。
**draft 的失败模式是「极少数极远的跳」，corr 的是「整体摊宽」。**

## 3. 为什么 $D_m$ 看不见：forward KL 按真值概率加权

`codes()` 把落在 `[edges[0], edges[-1]]` 之外的一切映射到**同一个 OUT-OF-SUPPORT 码**。两个后果叠加：

**(a) 幅度信息在分箱那一步就没了。** 价格偏 1100 tick 和偏 21402 tick 进同一个桶。

**(b) 那个桶的权重按构造为 0。** $\mathrm{KL}(p\|q)=\sum_k p_k\log(p_k/q_k)$ 逐箱**按 $p$ 加权**。
支撑集是用**真值分位数**定义的 ⇒ $p_{\rm true}(\text{OOS})=0$，平滑后 $4.59\times10^{-6}$：

| 生成端堆进 OOS 桶的质量 | 该桶对 forward KL 的贡献 |
|---:|---:|
| 1.08% | $-3.57\times10^{-5}$ nats |
| 9.78% | $-4.58\times10^{-5}$ nats |

**质量涨了 9 倍，贡献变化 $10^{-5}$ 量级。** 唯一的残余效应是**归一化**：越界带走 $\delta$ 的质量，
使支撑集内各箱同乘 $(1-\delta)$，给 KL 加 $-\log(1-\delta)$。

$$\Delta D=\frac{-\log(1-0.0978)+\log(1-0.0108)}{H=3.52}=+0.0262 \ \ \text{over } 1400 \text{ msgs}
\;\Rightarrow\; \text{slope } \mathbf{+0.00187}/100$$

而 A01 实测 `price_rel` @4× 的**可检下限是 0.0271** ⇒ **被压到噪声底以下 15 倍**。

**JS 在结构上不瞎但在数值上也不够**：JS 含 $q\log(q/m)$ 项，$p=0$ 时仍收费 $\tfrac12\delta\log 2$，
但换算后斜率只有 **+0.00061/100**，而 JS 的可检下限 0.0025 ⇒ **仍低 4 倍**。

> **结构性结论**：用真值分位数分箱 + forward KL，对「生成端跑出真值支撑集」这一类失败
> **几乎完全免疫**。而这恰恰是价格类字段最主要的失败模式。

## 4. 这改了 A01 的什么

| A01 的结论 | 处置 |
|---|---|
| 「`price_rel` 没有 compound error」 | ❌ **撤回**。改为「`price_rel` 有 compound error，A01 的度量对它结构性免疫」 |
| 「五个字段里只有 `size` 与 `log10_dt` 有」 | 修正为「**在分箱散度这把尺子下**只有这两个；换成越界质量与漂移跟随率，`price_rel` 也有，且更严重」 |
| `size` / `log10_dt` 的判定 | ✅ **不受影响**。两者的越界质量都很低，失败模式在支撑集内部，正是分箱散度看得见的那种 |
| 「DFM 能降低 compound error」 | ✅ **加强**。price 上多了一条独立且更大的证据（漂移跟随率 1.1% → 98.4%），代价是尾巴变肥 |
