## 4. 待答的那个问题

hybrid 在 4000–6000 之间发散（loss 3.18@6000、4.01@8000，baseline 同期 0.57–0.72）。
诊断跑带全套仪器（每 ~30 步记一次）已在跑，早期已见**间歇性梯度尖峰到 2.3**
而裁剪阈值是 1.0。

穿过发散区后三问一答：

| 问 | 看什么 |
|---|---|
| 哪一组先炸 | `grad_norms/{muon,ssm,regular,in_proj,out_proj}` 的相对时序 |
| 裁剪是不是一直饱和 | `grad_norms/clip_ratio` 是否持续 >1 |
| LR 有没有在那段被抬起来 | `lr` / `ssm_lr` 与 loss 同频，直接对齐看 |

**修法的约束**：不能只改 hybrid 的 LR/warmup，否则两臂多出一个变量，
「唯一改变的是序列长度」就不成立了。要么两臂同改，要么找只改数值不改优化的修法。
