# 【中途 profiling，非结论】2k 训练模型的第一次四臂对照（2026-08-13 09:41Z）

> ## 🟡 这不是实验报告
>
> **两条臂步数相差 25%**（baseline@1895 vs hybrid@2536，hybrid 多训 34%），
> 而 500 上下文那一轮里 baseline 从 12k 训到 32k 就让 L1 精确率从 63.5% 涨到 74.9%。
> **这个混淆足以解释下表的全部差距。**
>
> 它的价值在于：**第 4–6 步第一次在真正的 2k 训练模型上完整走了一遍**，
> 而不是在 500 上下文的代跑模型上。管线、口径、产物格式全部验证过了，
> 训练收敛后的正式对照是纯机械执行。

**设置**：N=512，cond1000/gen1000，seed 2026，跑在空闲的 6000409 上（不碰训练）。

## 3. 为什么仍然不能下结论

| 观察 | 也可以由什么解释 |
|---|---|
| 全线更好 | hybrid 多训 34% |
| 增益随距离放大 | 更多训练本身就先改善远端（500 上下文那轮 baseline 12k→32k 时 101–250 档涨了最多） |
| 远端两档 baseline 近乎为零（0.43% / 0.05%） | 1895 步的模型还没学会长距离回指，与架构无关 |

**唯一能分开的办法是在相同步数上重测。** 训练收敛后控制器会自动做这件事，
且会把两个真实步号与差值一并报出（>5% 触发告警）。

## 4. 这一轮确认可用的东西

- 2k 的 half-half 推理（cond1000/gen1000）在真实 2k 模型上跑通，生成形状与产物齐全
- (7.2)/(7.3)/(7.4) 三项打分全部产出，年龄分桶扩到 2000 后新增的两档有数据
- 全链路耗时：N=512 / 4 GPU，base 7:12、hyb 11:11（生成）+ 打分约 3 分钟
  → 外推 N=3136 约 **45 分钟 / 70 分钟**
- 训练全程未受影响（同时刻 baseline 6,329 步、1.71 it/s）
