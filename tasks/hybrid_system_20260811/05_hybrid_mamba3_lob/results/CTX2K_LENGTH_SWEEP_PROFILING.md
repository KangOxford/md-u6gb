# 【profiling，不是结论】hybrid 的退化随窗口长度：一次长度扫描（2026-08-12）

**对象**：500 上下文训练的 hybrid `j5980745@32001`（已收敛，末两点 CE 变化 −0.076%）。
**目的**：确认那个 74%→4% 是不是推理路径的缺陷。**若是，它会以同样方式毁掉最终的 2k 对照。**
**不是**：任何关于「hybrid 在长上下文上好不好」的结论。

---

## 1. 扫描结果

同一份代码、同一个 checkpoint、N=64、seed 2026，只改窗口：

| 设置 | cond token | gen token | L1 总 | 近端 1–10 |
|---|---:|---:|---:|---:|
| cond250 / gen250 | 6,500 | 6,500 | **74.48%** | 96.08% |
| cond500 / gen500 | **13,000** | 13,000 | **66.80%** | 89.41% |
| cond1000 / gen250 | **26,000** | 6,500 | **12.63%** | 21.46% |
| cond1000 / gen1000 | 26,000 | 26,000 | **4.33%** | 8.18% |

训练序列长度是 **13,000 token**。

```
 L1 精确
 75 ┤ ●  6.5k cond
 65 ┤      ● 13k cond  ← 正好等于训练长度
 45 ┤
 25 ┤
 12 ┤              ● 26k cond, 短生成
  4 ┤              ● 26k cond, 长生成
  0 ┼──────────────────────────────
    6.5k    13k        26k   条件段 token
```

---

## 2. ⭐ 崩塌只跟**条件段**长度走

`cond1000/gen250` 与 `cond1000/gen1000` 的生成长度差 4 倍，结果都在 4–13% 区间；
而 `cond500/gen500` 的**总长度在生成过程中同样会走到 26,000**，它却有 66.80%。

> **同样是 26,000 token，「生成到那里」没事，「条件在那里」就崩。**

一个可能的读法：`cond500/gen500` 里被打分的消息大多是在前缀还不到 20,000 时产生的，
平均前缀约 19,500；而 `cond1000/*` 里**每一条**生成的消息前缀都 ≥26,000。
这样看两者并不矛盾，膝点落在 20k–26k 之间。

**但这只是读法，不是证据。** 要判定需要按「产生该消息时的前缀长度」重新分箱，本轮没做。

---

## 3. 已排除的三件事

| 假设 | 排除依据 |
|---|---|
| 模型没收敛 | 末两点 CE 变化 −0.076%，已平 |
| 管线/代码坏了 | 控制实验 cond250/gen250 得 74.48–75.06%，复现已发表的 74.44% |
| KV cache 太短 | 确实曾只有一半（26,000 vs 需 52,000），已修（`32e09d3`）；修后 4.55%→4.33%，**非成因** |

---

## 4. ⭐⭐ 对最终实验的影响：**没有**

这一点是做这次扫描的唯一目的，结论是好的：

```
本轮：训练长度 13,000  →  推理长度 52,000     不匹配 4 倍
最终：训练长度 52,000  →  推理长度 52,000     匹配
```

**2k 训练的模型在评测时不会处于「前缀超出训练长度」的状态**，所以本轮观察到的现象
不会污染最终对照。这解除了我发起这次扫描时的担心。

---

## 5. 顺带修：验证器在 cond≠gen 时必然失败

`validate_model_zoo_evaluation.py` 用 `--rows N_GEN_MSGS` 去核对 `data_cond` 的行数。
cond==gen 时（250/250、1000/1000）恰好通过；cond1000/gen250 时报
`(path, 1000, 250)` 并让整个 bench 退出，**而生成本身是成功的**（4/4 批、32 条/rank）。
本轮用直接调用 `refer_success.py` 绕过。做非对称窗口的探针时要注意这一点。

---

## 6. 这份文件的定位

**profiling。** 它回答的是「最终实验会不会被这个现象毁掉」（答案：不会），
不回答「hybrid 在长上下文上是好是坏」。后者要等 2k 训练的两条臂，
现在 baseline 约 14%、hybrid 约 12%。
