# Learnt Lessons

## Writing decision

- When a proposed new moderator is empirically insignificant, do not preserve it just because it has theoretical appeal; revert to the more stable heterogeneity variable if it better matches validated evidence.
- For this CHARLS paper, the defensible model grammar is pension main effect -> psychological mechanism -> living-alone heterogeneity.
- Child transfer should not be kept as a co-equal explanatory variable when it is not significant in the main effect or psychological first-stage models.
- If life satisfaction is used as a headline outcome, avoid overclaiming loneliness as a mechanism unless the first-stage evidence supports it.

## Notion workflow

- If the user's new bracketed instruction appears inside a previous answer callout, process it by rewriting the target section and moving the processed prompt to a clean location with strikethrough.
- Re-fetch after replacing page content because Notion may escape LaTeX and comparison symbols in its markdown representation.
